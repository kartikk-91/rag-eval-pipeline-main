# Faithfulness labelling — 30 answers

**One question per item: did the answer stick to the passages shown below it?**

- `G` — everything the answer says is in those passages.
- `N` — the answer says something the passages do not contain.

Two rules that decide the hard cases:

1. **Do not judge whether the answer is true.** A correct fact that is not in the
   passages is still `N` — that is the model answering from memory, which is what
   this measures. Shared keywords are not support: the passage has to actually make
   the claim.
2. **"I don't know" cuts both ways.** `G` if the passages really lack the answer.
   `N` if the passages contain it and the model failed to use it.

Passages are shown **in full** — the same text the model received, nothing cut.
